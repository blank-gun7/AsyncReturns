> Generated by Opus planner agent. All file paths verified against the actual codebase.

## Context Findings (read before assigning any task)

1. **Pricing gap:** `constants.ts` has `CPM_INDIA_USD=5`/`CPM_GLOBAL_USD=15` but docs price blocks at $8/$15. `BlockPurchase` stores `price_per_block_usd` per-row. Task 3.0 must reconcile this first.
2. **No payment SDKs installed:** `razorpay`, `stripe`, PayPal absent — each billing task installs its own.
3. **No `src/dal/block-purchases.ts`:** webhook fulfillment needs this DAL — create in 3.0.
4. **`Wallet.payment_details` never captured in UI:** developer settings page shows method but has no form. Task 3.2a is a prerequisite for 3.3/3.4.
5. **`fraud.ts` rate-limiting is in-memory `Map`:** won't survive serverless/multi-instance. Task 4.4 replaces with Upstash Redis.
6. **Next.js 16 specifics:** error boundaries use `unstable_retry` (not `reset`) since v16.2.0. Read `node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/error.md` before 4.1.
7. **`proxy.ts` matcher already excludes** `api/auth`, `api/ads`, `api/webhooks` — webhook routes are correctly public.
8. **`/api/ads/impression` must return `impression.id`** for CLI click handling (task 3.6 dependency — assign explicitly).
9. **Decimal handling:** money columns are Prisma `Decimal`; convert with `Number(x)`. Webhook amounts in paise/cents — divide by 100.
